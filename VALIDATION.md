## Build and unit checks

With JAVA_HOME and ANDROID_HOME set as described in README.md:

```sh
./tools/build.sh
```

This assembles the signed release, runs JVM tests and release lint, and packages
local artifacts. To run only specific Gradle tasks:

```sh
./tools/build.sh :app:testDebugUnitTest :app:lintRelease
```

## Optional emulator checks

Use a **disposable emulator**, not a personal phone. These runners clear app data
and replace synthetic audio under `/sdcard/Music/LocalMusicQA`. They reject
physical-device serials. Fixtures require FFmpeg (or imageio-ffmpeg 0.6.0) and
mutagen 1.47.0 in a local Python environment; no copyrighted music is included.

```sh
python3 tools/make_sound_fixtures.py
python3 tools/sound_release_smoke.py --adb /path/to/adb --serial emulator-5556
python3 tools/library_release_smoke.py --adb /path/to/adb --serial emulator-5556
python3 tools/library_edge_smoke.py --adb /path/to/adb --serial emulator-5556
python3 tools/emulator_smoke.py --adb /path/to/adb --serial emulator-5556
```

The edge runner expects the state left by the library runner. The final playback
runner leaves a four-track paused queue used by the separate security probe.
Prepare that probe locally, then run the security checks:

```sh
mkdir -p .tooling
cp -R tests/security-probe .tooling/security-probe
./tools/build.sh -p .tooling/security-probe :app:assembleDebug
python3 tools/security_release_smoke.py --adb /path/to/adb --serial emulator-5556
```

The probe temporarily requests notification-listener trust on the disposable
emulator and revokes it afterward. Do not grant it access on a personal phone.
The upgrade assertion needs an already-installed build with matching signing
credentials; a new public checkout cannot update an unrelated private-key build.
